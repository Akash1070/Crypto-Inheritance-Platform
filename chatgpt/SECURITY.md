# Security Policy

This project is a security-sensitive design and implementation. Do not report vulnerabilities through public issues.

## Reporting

Before public launch, configure GitHub private vulnerability reporting or publish a monitored security contact address here. Do not invent an email address. Until a verified channel is configured, mark this repository as pre-release and do not accept real recovery secrets or real funds.

When reporting, include affected commit/version, impact, reproduction steps, and a safe proof of concept. Never include real seed phrases, private keys, wallet passwords, live share material, or personal data.

## Response policy

The maintainers will acknowledge receipt, triage severity, coordinate a fix, and publish an advisory after a fix or mitigation is available. Exact response SLAs must be established before public launch.

## Supported versions

No production version is currently designated by this project pack. Release support policy must be added before the first public release.
