# Prompts M0 to M3 (run one at a time, review each before the next)

Each prompt uses the `/build-milestone` workflow. After each: read the diff yourself, run `/security-review` in a **new conversation**, then commit and tag.

---
## M0 — Foundations
```
/build-milestone M0

Goal: monorepo skeleton and security tooling, no product code.
Deliver:
- pnpm workspace + Turborepo with apps/web, apps/api, apps/worker, apps/release-signer and packages/crypto-core, protocol, ui, cli (empty but typed, strict tsconfig).
- .npmrc with ignore-scripts=true, exact versions, lockfile.
- ESLint with security plugin + a custom rule/ boundary check that fails the build if any crypto library (libsodium, noble, node:crypto, WebCrypto subtle) is imported outside packages/crypto-core and packages/cli.
- Prettier, commitlint, husky pre-commit (gitleaks, typecheck, lint).
- GitHub Actions (pinned by commit SHA; no long-lived creds): pr.yml with typecheck, lint, tests, Semgrep, gitleaks, OSV-Scanner/pnpm audit, license check.
- CODEOWNERS for protected areas, PR template with the security checklist from docs/08, .env.example, SECURITY.md wired, docs/dependencies.md.
- docs/PROGRESS.md updated.
No application logic. Run /security-review at the end.
```

## M1 — crypto-core and CLI (highest risk; maximum scrutiny)
```
/build-milestone M1

Implement docs/04-SECURITY-ARCHITECTURE.md exactly. Do not deviate or add constructions; ask if anything is unspecified.
Deliver in packages/crypto-core:
- Vault format with version/suite header; AEAD encrypt/decrypt (XChaCha20-Poly1305 via libsodium) with AD binding vault id, version, purpose.
- Argon2id passphrase KDF with parameter minimums enforced on decode.
- Key generation, key wrap for OwnerWrap, sealing to a public key (per ADR-002).
- Shamir wrapper over the approved library, with share header (version, vault id) and an integrity commitment; reject mixed, duplicate, truncated, older-version shares.
- Ed25519 signing/verification helpers for event chain with canonical serialization.
- Zeroization helpers; generic error types.
Tests FIRST: KAT vectors (library + fixed), property tests (fast-check), tamper tests, downgrade tests, fuzz harness for decoders, cross-impl test between node and browser build. Target 100% line+branch, mutation score >= 80%.
packages/cli: `heirkey decrypt` offline command that reconstructs from shares and decrypts a pack file; `heirkey verify` stub.
Run crypto-change-review, then /security-review. List "Human review required" items. STOP at the end; G1 requires my review, G2 requires an external cryptographer.
```
